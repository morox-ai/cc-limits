Start it, now and at every login

Needs up-to-date Xcode Command Line Tools. On first launch macOS asks for keychain access: choose Always Allow. For Codex, sign in with codex login using a ChatGPT account.

Good to know.

Why is there a dim ∞ in my menu bar?
That provider hasn't loaded yet. Usually you're signed out or macOS is still waiting on keychain permission. To fix the second one, run brew services stop cc-limits, then cc-limits, choose Always Allow, quit from the menu and start the service again.
Does it work with an API key?
No. It reads subscription limits, so Claude Code needs its normal login and Codex needs a ChatGPT login. API keys get invoices instead.
How fresh are the numbers?
It asks every 5 minutes. Refresh now in the menu, or ⌘R while it's open, asks immediately.
Why build from source instead of a download?
You run the code you can read, and Gatekeeper has nothing to quarantine. Homebrew does the compiling.
Is this official?
Not even slightly. It's an independent project built on usage endpoints that aren't publicly documented, so an update on their side can break it.
