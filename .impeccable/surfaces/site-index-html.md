# Surface: cc-limits landing page

Scope and mode: the public website, one page. Persuade.
Audience and job: Mac developers on Claude Code or Codex subscriptions. Decide to install in under a minute.
Action: copy `brew install morox-ai/tap/cc-limits`.
Proof: an exact recreation of the status item and menu, live thresholds, the real `warningColor` source, and a plain table of what it reads and calls.
Constraints: no metaphors or themed worlds, the user rejected them outright. Style pinned to the user's apple-liquid-glass skill. No dependencies. Demo data only, never presented as real usage.

## Direction contract

THESIS: The product is the page. A tiny menu bar item is shown exactly as it renders, and the page refuses metaphor, feature-card grids and invented social proof.
OWN-WORLD: Cool #f5f5f7 ground, white panels with hairlines, system SF, graphite #17181b for the product stage. Blue only for action; amber #d99900 and red #db3833 only where the app itself uses them.
STORY: Visitors recognise the cutoff, see the bars and thresholds behave, confirm what it touches, then copy two commands.
FIRST VIEWPORT: Centered 88px "Know your limits.", one lede, the install command pill with copy. Below, a 1240px graphite macOS desktop that breaks out of the 1080 grid: glass menu bar, the status item, its menu open over a terminal.
FORM: Category standard, chosen after the user rejected all dealt directions; position: outside the ordered list; seed key de0e547e. Signature interaction: on load the Claude bar climbs across 60% into amber and the menu opens; sliders drive the exact status item and the hero menu; Dark/Light applies to the lab stage only.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
